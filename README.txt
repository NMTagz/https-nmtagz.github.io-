Files:

- assets/pastor-neil.jpg: supplied portrait

To preview: open index.html in a web browser (internet connection needed for the nature background image).

To publish for free with GitHub Pages:
1. Create a GitHub account at github.com.
2. Create a public repository named pastor-neil-ministries.
3. Upload index.html and the assets folder, keeping the same structure.
4. Go to repository Settings > Pages.
5. Under Build and deployment choose Deploy from a branch, main, /(root), and Save.
6. Wait for the published site URL to appear in Settings > Pages.

To personalize next:
- Provide your public Facebook profile link.
- Decide on a safe way to receive prayer requests (e.g. dedicated email or privacy-conscious form).
- Add individual sermon/devotional pages or videos.

Note: Free GitHub Pages uses a github.io URL. A custom domain generally costs extra.
The nature photograph is loaded from Unsplash remotely and requires internet access.
